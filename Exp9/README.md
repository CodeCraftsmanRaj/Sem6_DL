# Experiment 9: GAN on MNIST

This experiment implements a Generative Adversarial Network (GAN) using the MNIST handwritten digits dataset from `tf.keras.datasets.mnist`.

## Run

```bash
uv run python Exp9/exp9_gan_mnist.py
```
